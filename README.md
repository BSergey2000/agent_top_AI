# MCP Experiment Lab

В данной работе студенты исследуют возможности **MCP сервера (Model Context Protocol)** на основе библиотеки `FastMCP`.

Цель — понять, как работают основные компоненты MCP:

- **Prompt** — шаблоны инструкций для LLM
- **Tool** — функции, которые модель может вызывать
- **Resource** — внешние текстовые данные
- **Transport протоколы** — способы взаимодействия клиента и сервера


## Установка зависимостей

Перед началом работы установите все необходимые зависимости:

```bash
make setup
```

Затем создайте файл `.env` из шаблона и впишите свои ключи:

```bash
cp .env.example .env
```

| Переменная | Зачем нужна | Где получить |
|------------|-------------|--------------|
| `OPENROUTER_API_KEY` | Модель для агента | https://openrouter.ai/keys |
| `TAVILY_API_KEY` | Поиск в интернете для агента (удалённый MCP сервер Tavily) | https://tavily.com |

Ключ Tavily необязателен: без него агент использует локальный сервер DuckDuckGo, но тот часто возвращает пустую выдачу.

## Запуск MCP сервера Streamable HTTP

Для запуска MCP сервера в режиме Streamable HTTP необходимо выполнить две команды в разных терминалах.

### Терминал 1: Запуск MCP сервера

```bash
make mcp
```

### Терминал 2: Запуск MCP Inspector

```bash
make inspector
```

### Добавление своего MCP сервера в Inspector

Inspector по умолчанию показывает только примеры серверов. Свой сервер нужно добавить вручную.

1. В файле `.env` должно быть `IS_STDIO = 'False'`, иначе `make mcp` запустит сервер в режиме stdio.
2. Перезапустите `make mcp` и убедитесь, что в логе есть `http://127.0.0.1:8000`.
3. В браузере нажмите **Add Servers** и заполните форму:

| Поле | Что вписать |
|------|-------------|
| Server ID | `my-server` (любое имя из латинских букв, цифр, `-` и `_`) |
| Transport | `streamable-http` |
| URL | `http://127.0.0.1:8000/mcp` |

4. Нажмите **Add**, затем включите переключатель на карточке `my-server`. Статус должен смениться на **Connected**, и появятся вкладки Tools, Prompts и Resources.

> Если в логе сервера указан другой порт, подставьте его в URL вместо `8000`.
